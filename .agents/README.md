# Welcome to the Pagefind Bash Agent

I'm an assistant that can explore this site's content using a virtual bash environment.

### Capabilities:
- **Search**: Use `search "query"` to find relevant pages via Pagefind.
- **Read**: Use `fetch-internal "url"` to read the content of a page.
- **Tools**: Use standard bash commands (`ls`, `cat`, `grep`, `find`) to explore skills and metadata.
- **Web**: Use `web-search` and `web-fetch` for global information.

Try asking: "What is this blog about?" or "Find posts about BERT".
